Bigbools Pocket — game and emulator license record

This distribution contains unmodified ROM bytes encoded as JavaScript base64 payloads solely for transport through the portal's static-file allowlist. The browser decodes each payload byte-for-byte and verifies its SHA-256 digest before booting it.
